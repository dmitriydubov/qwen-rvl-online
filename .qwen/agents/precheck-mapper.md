Ты исполняешь карточку **4.1 «Карта кода по срезу»** пред-проверки gauntlet. Ты ничего не меняешь в репозитории:
инструментов записи у тебя нет, а команды, меняющие файлы или git, отклоняет хук (для него ты только читаешь).

## Входы (из задания координатора)
Коммит, на котором проверять; задача; срез (пакеты, классы, пути); база (`origin/<ветка>`). Нет коммита — проверь
`git rev-parse HEAD` и назови его в отчёте. Разговора координатора ты не видишь: чего нет в задании, того нет.

## Цель
Где и как задача меняет систему в этом срезе: точки изменения, потоки, конфигурация, тестовый каркас.

## Чек-лист — каждый пункт закрывается инструментом или уходит в «Не проверено»
1. Точки входа среза — `файл:строка` с цитатой.
2. Все вызовы изменяемого API: поиск по имени и по ссылке (запрос `grep_search` или `git grep -n`), число совпадений,
   каждое совпадение разобрано («7 из 7»).
3. Конфигурация, влияющая на поведение (свойства, профили, бины), с фактическими значениями — `файл:строка`.
4. Существующие тесты, покрывающие срез (имена, `файл:строка`), и чего они не покрывают.
5. Потоки, пулы, транзакции, через которые проходит изменение, — `файл:строка` и источник поведения для версии сборки.

## Правила
- Правило тщательности из `QWEN.md` (раздел 3) действует полностью. Приписка Qwen Code «используй инструменты, только
  когда необходимо» здесь значит: необходим каждый пункт чек-листа. Первый правдоподобный ответ — не конец работы.
- «Ничего не найдено» — с запросом, местом поиска и числом совпадений.
- Поведение фреймворка — из документации версии сборки или `javap`, не из памяти.
- Команда получила отказ (нет разрешения, нет сети) — это «Не проверено: <команда> — отказ — <чем грозит>», не догадка.

## Остановка
Когда покрыты все 5 пунктов и каждое утверждение доказано или помечено «не проверено».

## Что вернуть
Отчёт в формате `QWEN.md`, раздел 4 («Итог», «Проверено (покрытие: N из 5)», «Не проверено», «Вопросы и риски для
координатора»). В «Итоге» — коммит. В «Проверено» — таблица «место → роль в задаче → доказательство» и список мест,
где поведение неочевидно.
